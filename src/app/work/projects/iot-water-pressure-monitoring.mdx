## Overview

This project involved the development and implementation of an IoT-based water pressure monitoring system during my internship at PDAM Toya Wening (PDAM Surakarta).

The system uses ESP32 and water pressure sensors to collect and monitor water pressure data across the distribution network.

## My Contributions

- Assisted in developing and implementing the IoT monitoring device using ESP32.
- Supported installation and configuration at more than 10 monitoring points.
- Assisted with sensor calibration and device troubleshooting.
- Supported real-time monitoring dashboard and database integration.

## Technologies

- ESP32
- Water Pressure Sensor
- Internet of Things (IoT)
- Web Monitoring Dashboard
- Database Integration

## Outcome

Contributed to the implementation of an IoT-based water pressure monitoring system to support monitoring activities within the PDAM water distribution network.

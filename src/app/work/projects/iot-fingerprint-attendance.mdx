## Overview

This project was developed as my undergraduate thesis, focusing on an IoT-based employee attendance system using fingerprint recognition at Waroeng Kuota.

The system uses an ESP32 microcontroller and an AS608 fingerprint sensor to record employee attendance, with a web-based dashboard for attendance data management.

## My Contributions

- Designed and developed the IoT-based fingerprint attendance system.
- Integrated the AS608 fingerprint sensor with ESP32.
- Implemented RTC DS3231 for time recording.
- Integrated an LCD I2C display and buzzer for system feedback.
- Developed a web-based attendance dashboard using PHP and MySQL.
- Implemented attendance data recording and monitoring.

## Technologies

- ESP32
- AS608 Fingerprint Sensor
- RTC DS3231
- LCD I2C
- PHP
- MySQL

## Outcome

Developed a functional prototype of an IoT-based attendance system that supports employee attendance recording and centralized data monitoring through a web dashboard.
